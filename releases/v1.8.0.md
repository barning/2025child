# Release v1.8.0

**Release date:** 2026-10-29

## Highlights

- Added automatic light and dark appearances that follow the visitor's operating-system preference.
- Preserved Twenty Twenty-Five's default light palette while adding a neutral, warm dark palette with accessible contrast.
- Updated custom block surfaces, controls, borders, placeholders, and muted text to use shared adaptive color tokens.
- Kept the Site Editor canvas and color controls aligned with the front-end appearance.
- Added matching light and dark browser chrome colors for compatible mobile browsers.
- Added light-mode fallbacks for browsers without `light-dark()` support.
- Added automated palette, contrast, asset, metadata, and packaging regression checks.

## Compatibility

Existing block attributes and saved content remain unchanged. Sites with saved Global Styles color overrides must maintain paired light and dark values for automatic switching to remain complete.

## Deployment

After activating the release, clear page and persistent object caches so WordPress regenerates the child theme's Global Styles output from `theme.json`.
