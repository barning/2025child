# Release v1.8.1

**Release date:** 2026-10-29

## Fixes

- Restored readable dark-mode foreground colors when a site has saved Global Styles color overrides.
- Added accessible dark-mode colors for global links, link hover states, and buttons while preserving their existing light appearance.
- Kept Twenty Twenty-Five section styles in control of their contextual link colors and restored the Section 5 button pairing.
- Added regression coverage for the saved-Global-Styles failure seen on the live site.

## Compatibility

This is a CSS-only compatibility fix. It does not alter saved Global Styles, block attributes, content, cookies, or database data.

## Deployment

Replace v1.8.0 with v1.8.1 and clear page caches so the updated `style.css` is served with the new theme version.
