# Release v1.7.0

**Release date:** 2026-07-28

## Highlights

- Corrected the document outline so recommendation-card labels no longer create unrelated headings.
- Added intrinsic image dimensions throughout custom block output to reduce layout shifts.
- Added reduced-motion behavior for every animated custom block and the theme’s global hover effect.
- Switched block controls, defaults, errors, and the visual test fixture to German.
- Removed the global dynamic-block stylesheet fallback; WordPress now loads front-end block styles from block metadata only when needed.
- Added automated regression checks for headings, image dimensions, reduced motion, conditional styles, and the German fixture locale.

## Compatibility

Existing block attributes remain compatible. The German default for Popular Posts applies to new blocks; saved custom titles are unchanged.

## Deployment

Before production deployment, complete the hosting-level checklist in the project README. Those HTTP, TLS, caching, compression, and error-page requirements cannot be guaranteed by a WordPress theme.
