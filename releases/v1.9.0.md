# Release v1.9.0

**Release date:** 2026-11-04

## Highlights

- Added linear threads to the existing Note custom post type.
- Added a searchable editor panel for choosing the previous Note.
- Rendered complete Note conversations on every member permalink.
- Added append-only relationship validation and tail-only deletion safeguards.
- Added native ActivityPub `inReplyTo` and Bluesky reply references.
- Added compatibility guards for sites without either federation plugin.

## Compatibility

Existing Notes remain independent thread roots and require no migration. Full
federation support targets ActivityPub 9.4.2 or newer and ATmosphere 2.5.0 or
newer. WordPress-only threads continue to work when either plugin is absent.

## Deployment

After updating, clear page caches. If an older Note should become the parent of
a Bluesky thread but has not been shared yet, backfill it with ATmosphere before
publishing its continuation.
